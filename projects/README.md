## Create a New Project

```bash
./scripts/new-project.sh project-name
```

## Rules

- Folder name: lowercase, hyphenated. Example: `toko-online`.
- Each project has a `README.md`: purpose, status, how to run.
- Update status in the project `README.md`, then run `./scripts/index-projects.sh`.
- Diagrams and cross-project notes go in `docs/`, not here.
